
# Project Liftlog Frontend

Vue.js-Frontend für die Webanwendung Liftlog.

## Projektidee

Liftlog unterstützt Nutzer dabei, absolvierte Krafttrainings-Sätze zu dokumentieren
und ihren Trainingsfortschritt später auszuwerten.

## Aktueller Milestone M2

- Vue.js-App mit Vite erstellt
- Eigene Unterkomponente `TrainingSetList.vue` erstellt
- Beispiel-Entitäten als JavaScript-Array angelegt
- Beispiel-Trainingssätze mit `v-for` in einer Tabelle gerendert
